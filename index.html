📥 Installation Guide

✓ Minimum Requirements

  • Java 21+
  • 2GB RAM
  • Minecraft 1.21.1
  • Fabric Loader

✓ Recommended Requirements

  • Java 21 (Latest)
  • 4GB+ RAM
  • SSD Storage
  • NVIDIA/AMD GPU
1

Download Fabric Loader

Visit fabricmc.net and download the installer for Minecraft 1.21.1

fabricmc.net/use/installer
2

Run Fabric Installer

Execute the downloaded installer and select your Minecraft installation

Fabric Installer v0.20.1
3

Download 76 Client JAR

Download the latest 76 Client build from the releases page

client76-1.0.jar
4

Place Files in Mods Folder

Move both JAR files to your .minecraft/mods directory

%appdata%\.minecraft\mods\
5

Launch Minecraft

Start Minecraft with the Fabric profile and press Right Shift to open ClickGUI

Press Right Shift in-game
