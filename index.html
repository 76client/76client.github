📥 Installation Guide

1

Download Fabric Loader

Visit fabric.net and download the latest Fabric Loader installer for Minecraft 1.21.1

https://fabricmc.net/use/installer/
2

Install Fabric

Run the Fabric installer and select Minecraft 1.21.1. Click "Install"

Select Version: 1.21.1 → Click Install
3

Download Fabric API

Download Fabric API for version 1.21.1 from modrinth.com

https://modrinth.com/mod/fabric-api
4

Download 76 Client

Download the latest 76 Client build (client76.jar) from our releases page

Place in: .minecraft/mods/
5

Launch & Enjoy

Select Fabric profile in Minecraft Launcher and launch the game. Press RSHIFT to open ClickGUI!

Keybind: Right Shift (RSHIFT) to toggle GUI
