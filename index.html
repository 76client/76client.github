📥 Installation Guide

✓ Requirements

  • Minecraft 1.21.1
  • Fabric Loader 0.20+
  • Fabric API
  • Java 21+

Step 1: Install Fabric Loader

Download from fabricmc.net and run the installer

Step 2: Download 76 Client

Get the latest build from releases

client76-1.0.jar

Step 3: Place JAR in Mods Folder

Move to .minecraft/mods/ directory

%appdata%\.minecraft\mods\

Step 4: Install Fabric API

Download and place in mods folder (same as step 3)

Step 5: Launch & Play

Start Minecraft and press Right Shift to open ClickGUI

🔑 Default Keybinds

Right Shift - Open ClickGUI

P - Panic Module
